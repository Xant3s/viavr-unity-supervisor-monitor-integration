# Read me

## Set up sample Scene

For the sample to work properly you need to provide the file path to the ResultScene which is also provided in the sample folder. Also the "ResultScene" needs to be added in the BuildSettings.

## Setting up Config files

FOr the automatic creation and set up of the gameObjects necessary to create the Events, you need to provide a config file in the "Settings/de.jmu.ge.viavr.webstreaming" folder.
